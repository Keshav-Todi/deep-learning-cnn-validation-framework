# CNN Image Classification Pipeline

## Overview
This project implements a Convolutional Neural Network (CNN) for image classification using TensorFlow/Keras. The focus is on understanding deep learning architecture design and structured validation techniques.

## Key Components
- Multi-layer Conv2D architecture
- MaxPooling layers
- Dense output layer
- Model compilation and training
- Stratified cross-validation
- Parameter tuning (filters, learning rate)

## Objective
The purpose of this project was to gain foundational experience in deep learning model construction, training workflows, and performance evaluation.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Scikit-learn

## Learning Outcome
This project helped me understand:
- Feature extraction through convolution
- Training and validation loops
- Model tuning in neural networks
- Structured experimentation in deep learning
